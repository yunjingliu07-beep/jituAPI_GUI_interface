# 站长用户与调用记录

站长登录后，侧栏显示「用户与调用记录」。普通成员与管理员都不能读取此页面的数据，直接请求接口同样会被拒绝。

- 「注册用户」：总账号数、邮箱、身份、注册时间、任务数、实时调用次数、最近实时调用。点击邮箱查看该账号的调用记录。
- 「API 调用」：邮箱、请求开始与响应时间、模型、模式、申请张数、HTTP 状态、请求结果、任务最后状态和任务编号。支持邮箱包含搜索、日期范围、每页 50 条分页及手动刷新。
- 所有日期范围按 UTC+8 的自然日计算，结束日期包含全天；用户页按注册日期筛选，调用页按调用日期筛选。用户页的任务和调用次数为账号累计值。

## 记录口径

`api_activity` 独立保存生图请求的运营记录，不保存提示词、图片、密码、Cookie 或 API 密钥。每次实际向供应商提交生成请求前先登记；失败与重试分别计次。重复读取已经受理的同一任务、轮询查询、下载、参数校验失败不增加调用次数。这不是 PV/UV 或全站 HTTP 请求统计。

任务后续查询会更新最后已知任务状态，不会在后台主动调用用户 API。删除聊天及自动空间清理不删除运营记录。API 请求被受理不代表生成成功、实际张数或扣费；本页面不推算费用。若进程在请求后中断，记录可能停留在等待响应，必须用任务编号向供应商核对。

迁移 `0006_owner_activity.sql` 为仍存在的旧任务回填一条 `historical` 记录。该时间是任务创建时间，不是准确 API 请求时间；无法恢复之前已删除的任务或历史重试。历史记录不计入「实时调用次数」。重复运行迁移不会重复回填。

## Ubuntu 更新

本次没有修改 `RELEASES`，不会因这次改动新增全体用户更新日志或更新通知。更新前应在服务停止期间备份整个数据目录，避免只复制正在使用的 SQLite 主文件。

仓库位于 `/opt/image-meow`、正式域名为 `imagemeow.top` 的默认部署可在 Workbench 运行：

```bash
cd /opt/image-meow
sudo git pull --ff-only origin main
sudo bash deploy/ubuntu/update.sh
```

更新脚本会停止服务、在私有目录备份数据、应用增量迁移、启动服务，并检查健康状态；不会更改域名、TLS、加密主密钥或站长权限。旧版本无法在网页中显示新入口，成功后需刷新网页。
