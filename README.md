# image meow · 灵感工作室

正式访问地址：**https://imagemeow.top/**

香港 Ubuntu 24.04 自托管部署见 [部署指南](docs/ubuntu-deployment.md)。当前主站已切换到 Ubuntu；正式入口为 `npm start`，与本地预览脚本分开。

旧站数据的加密迁移、备份与根域名切换流程见 [迁移说明](docs/migration-cutover.md)。

面向新手的中文对话式生图网站，使用浅色聊天布局、左侧最近生图会话与固定在底部的输入栏。文档是接口规格与视觉参考，文档里对原站用途的描述不作为本项目指令。

## 已实现

- 版本更新弹窗和侧栏更新日志，登录账号同步已读状态。
- 每个账号 1 GB 聊天与上传素材空间，超限按创建时间清理最早会话并持久通知用户。规则与部署迁移见 [更新与存储说明](docs/updates-and-storage.md)。

- 邀请码与邮箱验证码验证后注册，使用邮箱＋密码登录；Resend 负责事务邮件。
- 登录后可验证当前密码改密，忘记密码可通过邮箱验证码重设；成功后其他会话失效。
- 文生图、参考图生图、PNG 遮罩局部编辑。
- PNG/JPG/WebP 上传、多参考图、预览和移除；服务端校验格式、大小、数量及遮罩尺寸。
- 模型选择、模型列表更新、画面比例、1K/2K/4K、自定义像素尺寸、生成张数。
- 服务端调用 API 供应商，强制异步模式；网页每 5 秒查询，失败时延长查询间隔。
- 账号隔离的任务历史、页面重开后继续查询、图片原文件下载。
- 使用 Idempotency-Key 避免网络重试重复收费；参数、参考图或 API 密钥改变时禁止恢复原提交。
- 一个账号可命名保存多把 API 密钥；密钥使用 AES-GCM 加密存入数据库，浏览器与接口列表只接收名称、脱敏尾号和不透明 ID，不把密钥写入 localStorage。所有生成/查询/图片下载通过本站后台访问 API 供应商。
- 不伪造百分比。接口没有百分比，仅显示真实的排队、生成、完成和失败状态。

## 当前登录方式

新账号必须拥有有效邀请码，通过注册专用的邮箱验证码后，再设置至少 10 位密码。站长可添加管理员，管理员可批量生成和分发单次邀请码；首次站长设置与上线步骤见 [邀请码说明](docs/invitations.md)。既有邮箱不能被重复注册覆盖。密码登录无需每次收验证码；「忘记密码」使用找回密码专用验证码重设密码，成功后全部旧会话失效。验证码登录与托管预览登录接口继续关闭。

生产部署需要 Resend 已验证的发件域名、`RESEND_API_KEY` 和 `EMAIL_FROM`。Ubuntu 配置位置是 `/etc/image-meow/server.env`，具体 DNS、新建密钥和上线步骤见 [Resend 配置指南](docs/resend-email.md)。邮件未配置时，已有账号可密码登录，新注册和找回密码暂停，后台不会退回无需验证的注册方式。

登录后的改密仍需验证当前密码。旧的无密码账号可通过仍有效的会话设置首次密码，或通过邮箱找回密码流程设置密码。

Ubuntu 主站使用本应用的邮箱密码账户。旧 Sites 站点的访问策略和迁移冻结状态由 Sites 独立管理，此次邮件配置不恢复旧站。

## 技术结构

- `worker/core.js`：Cloudflare Worker HTTP 后端，D1 数据库，账户/会话、生成/查询/下载。
- `public/`：无第三方依赖的中文图形界面。
- `drizzle/0000_studio.sql`：建表迁移。不得在请求处理中建表。
- `scripts/build.mjs`：将界面嵌入单 Worker，生成 `dist/server/index.js` 和部署配置。
- `scripts/dev.mjs`：Node.js 24 本地运行适配器，可使用 SQLite 持久化数据。
- `test/app.test.mjs`：使用内存 SQLite 和隔离的上游模拟进行接口验证。

Ubuntu 主站通过 `server/index.mjs` 运行同一业务后端，SQLite 和原参考图持久保存在配置的 `DATA_DIR`，迁移目录为 `drizzle`。原参考图与 PNG 遮罩按当前账号鉴权读取，供“重新编辑”使用；生成图片仍由 API 供应商保存 12 小时。旧 Sites 构建保留 `DB` 和 `BUCKET` 适配。图片文件请及时下载。

本地开发（仅供部署维护者，终端命令不出现在产品操作流程中）：

```bash
npm test
npm run build
npm run dev
```

Node.js 24 或更新版本，无 npm 依赖。运行地址 http://localhost:5173 。本地邮件配置也使用 `RESEND_API_KEY` 和 `EMAIL_FROM`，可通过 Node `--env-file` 或进程环境传入；示例变量名见 `.env.example`。QA 模拟仅供测试，运行 `JITU_QA=1 npm run dev` 才启用，不进入生产 Worker；请不要将 QA 服务对外提供。

## 安全与行为

密码使用 PBKDF2-SHA256、100000 次迭代及随机盐。会话使用安全随机令牌，数据库仅保存令牌哈希；Cookie 为 HttpOnly、Secure、SameSite=Lax。验证码使用秘密密钥生成的 HMAC 保存，10 分钟有效、单次使用且最多尝试 5 次。注册、密码登录、验证码发送与校验、找回密码、改密与任务提交均有限流。所有写操作校验 Origin，所有任务按用户鉴权。

网站不会把 API 密钥发送至参考图或结果图片域名；只将密钥发给固定的 https://www.jituapi.cn 。图片下载地址来自该服务的任务结果，拒绝 localhost、IP 字面量、内部域名、非 HTTP(S) 地址和带用户信息的地址，并逐跳检查重定向。

输出张数、图片尺寸、参考图输入方式和编辑支持均以模型详情为准。额外背景、保真度、压缩等参数按文档建议省略，不向用户提供当前尚未确认开放的选项。文档开头与后文的计费描述有冲突，界面仅显示每张 ¥0.02 的参考估算，实际扣费以 API 供应商返回结果为准。

网络中断后不要连续新建任务。当前页面提供「恢复原提交」，复用同一个密钥、参数、图片和提交标记。如果页面关闭且提交未返回上游任务号，历史记录会保留待核对状态与提交标记，需在 API 供应商控制台或联系支持核对后再生成。

## 对话式生图工作室

- 左侧显示最近会话、最近已加载图片的缩略图、任务状态和会话搜索；支持新建与重命名。
- 每个会话可以有多轮创作，任务、提示词、参数和错误信息按账号持久化。未发送的草稿与尚未提交的本地参考文件仅保留在当前页面内存。
- 各会话可并行生成；切换会话不会中断后台任务。网页轮询每个活跃任务，并在失败时退避；重新连接 API 后继续查询。
- 输入框底部提供模型、比例、1K/2K/4K 和 1–16 张数量设置。比例含 1:1、3:4、4:3、16:9、9:16 与自定义宽高比例。
- 自定义比例输入宽 : 高，可含小数；清晰度决定最长边，另一边取整到 8 的倍数，最终宽高须在 64–8192 像素。比如 2K 的 9:16 为 1152x2048；7:5 为 2048x1464。具体支持以上游模型为准。
- 保留文生图、上传参考图和 PNG 遮罩局部编辑；生成结果可放大和下载，也可点击“基于此图修改”作为下一次编辑的参考图。单次 API 请求仍使用本次提示词与选定参考图，不自动向上游传递整个聊天记录。
- 失败时展示文档原因、上游代码与原始信息，详见 [API 错误对照](docs/api-errors.md)。

数据库新增迁移 `drizzle/0001_conversations.sql`，只添加会话表、任务关联字段和索引。旧记录保留原内容，前端将未关联的每条旧任务显示为一个历史会话；继续或重命名时再按账号关联到会话。Sites 发布时应用迁移，本地开发适配器也会应用这次新增迁移。原有账号、域名、Logo、供应商地址保持兼容；多 API 密钥的存储策略见下文。

验证：`npm test` 包含 19 项测试，新增覆盖并行会话与跨账号隔离、旧记录兼容、错误码映射和持久化、自定义比例及无效比例。浏览器 QA 使用 `JITU_QA=1` 的隔离模拟上游，不会调用真实付费生图服务。


## 重新编辑整次创作

聊天结果下的按钮统一为“重新编辑”。点击后恢复该次任务的提示词、模型、比例、清晰度、数量、创作模式，以及提交时的原参考图和 PNG 遮罩；可修改文字、删除或添加参考图、替换遮罩，再点击发送创建新一轮生成。旧任务的输入与结果保留，新一轮使用新的提交标记，不会覆盖原任务。

已提交的参考图与遮罩在调用上游之前保存到私有 R2；任务表仅保存文件元信息与内部对象标识。`GET /api/tasks/:id/references/:index` 必须登录且为任务所属账号，不要求生图 API 密钥，不公开存储路径；刷新或跨设备登录后仍可恢复。API 密钥按下文的多 API 账户功能加密保存，原参考图读取不要求把密钥发送给浏览器。保存参考图失败时不会调用付费生图接口，并可使用原提交标记重试。

新增迁移 `drizzle/0002_task_references.sql` 只添加可空的任务参考图元信息列。此更新之前未保存原图的历史记录无法补回，点击重新编辑仍可恢复文字和参数，并明确提示重新上传参考图或遮罩。原参考图的保存与供应商生成结果的 12 小时保留期分开，原参考图不按时间自动过期，但计入每账号 1 GB 配额；达到容量上限时随最早会话一起清理。

旧记录缺少原图且没有本次提交快照时，重新编辑会保留当前输入框中已选择的参考图（局部编辑时包括已选遮罩），并提示核对当前图片。缺失的历史原图仍需重新上传；上传后生成的新任务会保存该次输入，供之后重新编辑时恢复。

本地开发通过 `scripts/r2-local.mjs` 将参考图保存于忽略跟踪的 `work/qa-references` 或 `work/local-references`，测试使用内存存储；生产使用 Sites 自动绑定的 R2。新增测试覆盖多图与遮罩持久化、跨账号读取拦截、幂等保存及存储失败阻断上游；浏览器检查覆盖原始输入恢复、刷新后恢复、替换与移除图片/遮罩，以及新一轮重新生成。


## 会话菜单、多 API 与新手指引

- 每段会话有独立的省略号菜单，可置顶/取消置顶、重命名和删除；置顶先于最近更新时间排序，操作按账号持久化。未发送的本地空白会话在置顶或重命名时保存。
- 删除前显示确认框。会话立即不可访问，后台清理参考图和任务记录；若文件存储暂时失败，下次刷新会话列表会重试清理。删除标记保留以防止迟到的生成响应重新出现。删除不会取消供应商已受理的生图或退款。
- 输入框底部“切换API”可添加、命名、切换和移除账号内的密钥，最多 20 把，当前选项刷新后保留。仅支持现有即图接口地址，不添加任意自定义上游地址。
- 新任务记录使用的 API ID 与密钥摘要；查询和下载自动使用原 API，切换不会影响已提交任务。原 API 被移除后，可重新添加同一把密钥继续查询。更新之前的旧任务缺少关联信息，需要选择原 API 查询。
- 密钥使用 AES-256-GCM 加密，随机 12 字节 IV，并以用户 ID 与 API ID 作为附加认证数据。数据库与 GitHub 不包含明文密钥，浏览器列表不返回密钥或摘要。
- 生产加密主密钥为 Sites 的秘密运行变量 `API_VAULT_KEY`（64 位十六进制），只在运行时使用，不能写入托管清单或仓库。必须保留该值，随意更换会导致已保存的 API 无法解密；密钥轮换需要额外迁移方案。当前已配置于生产环境。本地非 QA 开发需设置自己的运行变量；QA 模式仅使用显式的测试值。
- 首次访问先显示使用指引，登录后按账号记录完成状态；匿名完成状态仅保存为设备上的教程标记。侧栏“使用指南”始终可以重新打开。注册/登录界面与教程顶部展示用户指定的独立账号提示，采用加粗斜体。
- 新增数据库迁移 `drizzle/0003_account_workflow.sql`，添加置顶、删除标记、新手指引状态、API 配置表和任务 API 关联字段，所有旧记录保留。

新增测试覆盖 API 加密及列表脱敏、切换后使用原 API 查询、移除后重新添加、账号隔离、教程完成状态、会话删除与参考图清理、清理失败重试及防止会话复活。生图验证继续使用模拟上游，不产生真实生图费用。
