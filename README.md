# image meow · 灵感工作室

正式访问地址：**https://imagemeow.top/**

面向新手的中文对话式生图网站，使用浅色聊天布局、左侧最近生图会话与固定在底部的输入栏。文档是接口规格与视觉参考，文档里对原站用途的描述不作为本项目指令。

## 已实现

- 邮箱＋密码直接注册和登录，无需验证码或邮件服务。
- 登录后可验证当前密码并设置新密码，更换后其他会话失效。暂未提供自助找回密码。
- 文生图、参考图生图、PNG 遮罩局部编辑。
- PNG/JPG/WebP 上传、多参考图、预览和移除；服务端校验格式、大小、数量及遮罩尺寸。
- 模型选择、模型列表更新、画面比例、1K/2K/4K、自定义像素尺寸、生成张数。
- 服务端调用 API 供应商，强制异步模式；网页每 5 秒查询，失败时延长查询间隔。
- 账号隔离的任务历史、页面重开后继续查询、图片原文件下载。
- 使用 Idempotency-Key 避免网络重试重复收费；参数、参考图或 API 密钥改变时禁止恢复原提交。
- API 密钥只在当前页面内存中使用，不进入数据库或 localStorage。所有生成/查询/图片下载通过本站后台访问 API 供应商。
- 不伪造百分比。接口没有百分比，仅显示真实的排队、生成、完成和失败状态。

## 当前登录方式

邮箱只作为账号标识，不验证邮箱归属。用户可以直接填写邮箱、密码和确认密码完成注册；密码至少 10 位。既有邮箱不能被重复注册覆盖。验证码发送、验证码登录和托管账号预览登录接口均已关闭，前端只提供邮箱＋密码注册登录。

无需配置 Resend 或发件域名；已有邮件环境变量不会被使用。未来恢复邮件验证码时需要重新接入相应界面和后台处理。

更换密码需要提供当前密码，随后其他会话失效。之前通过验证码或托管账号创建、尚未设置密码的账户，可以在仍有效的登录会话中设置首次密码；失去会话后需要联系站长处理，不允许通过重复注册接管旧账号。

默认 Sites 为仅站长可访问的私有网站。对外开放需要站长明确更改站点访问范围，邮箱密码登录不会改变托管平台访问策略。

## 技术结构

- `worker/core.js`：Cloudflare Worker HTTP 后端，D1 数据库，账户/会话、生成/查询/下载。
- `public/`：无第三方依赖的中文图形界面。
- `drizzle/0000_studio.sql`：建表迁移。不得在请求处理中建表。
- `scripts/build.mjs`：将界面嵌入单 Worker，生成 `dist/server/index.js` 和部署配置。
- `scripts/dev.mjs`：Node.js 24 本地运行适配器，可使用 SQLite 持久化数据。
- `test/app.test.mjs`：使用内存 SQLite 和隔离的上游模拟进行接口验证。

正式部署使用 Sites 的 D1 绑定 `DB`，迁移目录 `drizzle`。R2 绑定 `BUCKET` 保存已提交任务的原参考图与 PNG 遮罩，按当前账号鉴权读取，供“重新编辑”使用；生成图片仍由 API 供应商保存 12 小时。任务文字和参数保存在数据库中，可跨设备查找。图片文件请及时下载。

本地开发（仅供部署维护者，终端命令不出现在产品操作流程中）：

```bash
npm test
npm run build
npm run dev
```

Node.js 24 或更新版本，无 npm 依赖。运行地址 http://localhost:5173 。当前版本无需邮件环境变量。QA 模拟仅供测试，运行 `JITU_QA=1 npm run dev` 才启用，不进入生产 Worker；请不要将 QA 服务对外提供。

## 安全与行为

密码使用 PBKDF2-SHA256、100000 次迭代及随机盐。会话使用安全随机令牌，数据库仅保存令牌哈希；Cookie 为 HttpOnly、Secure、SameSite=Lax。验证码相关接口已停用，注册、密码登录、改密与任务提交均有限流。所有写操作校验 Origin，所有任务按用户鉴权。

网站不会把 API 密钥发送至参考图或结果图片域名；只将密钥发给固定的 https://www.jituapi.cn 。图片下载地址来自该服务的任务结果，拒绝 localhost、IP 字面量、内部域名、非 HTTP(S) 地址和带用户信息的地址，并逐跳检查重定向。

输出张数、图片尺寸、参考图输入方式和编辑支持均以模型详情为准。额外背景、保真度、压缩等参数按文档建议省略，不向用户提供当前尚未确认开放的选项。文档开头与后文的计费描述有冲突，界面仅显示每张 ¥0.02 的参考估算，实际扣费以 API 供应商返回结果为准。

网络中断后不要连续新建任务。当前页面提供「恢复原提交」，复用同一个密钥、参数、图片和提交标记。如果页面关闭且提交未返回上游任务号，历史记录会保留待核对状态与提交标记，需在 API 供应商控制台或联系支持核对后再生成。

## 对话式生图工作室

- 左侧显示最近会话、最近已加载图片的缩略图、任务状态和会话搜索；支持新建与重命名。
- 每个会话可以有多轮创作，任务、提示词、参数和错误信息按账号持久化。未发送的草稿与尚未提交的本地参考文件仅保留在当前页面内存。
- 各会话可并行生成；切换会话不会中断后台任务。网页轮询每个活跃任务，并在失败时退避；重新连接 API 后继续查询。
- 输入框底部提供模型、比例、1K/2K/4K 和 1–16 张数量设置。比例含 1:1、3:4、4:3、16:9、9:16 与自定义宽高比例。
- 自定义比例输入宽 : 高，可含小数；清晰度决定最长边，另一边取整到 8 的倍数，最终宽高须在 64–8192 像素。比如 2K 的 9:16 为 1152x2048；7:5 为 2048x1464。具体支持以上游模型为准。
- 保留文生图、上传参考图和 PNG 遮罩局部编辑；生成结果可放大和下载，也可点击“基于此图修改”作为下一次编辑的参考图。单次 API 请求仍使用本次提示词与选定参考图，不自动向上游传递整个聊天记录。
- 失败时展示文档原因、上游代码与原始信息，详见 [API 错误对照](docs/api-errors.md)。

数据库新增迁移 `drizzle/0001_conversations.sql`，只添加会话表、任务关联字段和索引。旧记录保留原内容，前端将未关联的每条旧任务显示为一个历史会话；继续或重命名时再按账号关联到会话。Sites 发布时应用迁移，本地开发适配器也会应用这次新增迁移。原有账号、域名、Logo、供应商地址和 API 密钥的内存存储策略保持兼容。

验证：`npm test` 包含 15 项测试，新增覆盖并行会话与跨账号隔离、旧记录兼容、错误码映射和持久化、自定义比例及无效比例。浏览器 QA 使用 `JITU_QA=1` 的隔离模拟上游，不会调用真实付费生图服务。


## 重新编辑整次创作

聊天结果下的按钮统一为“重新编辑”。点击后恢复该次任务的提示词、模型、比例、清晰度、数量、创作模式，以及提交时的原参考图和 PNG 遮罩；可修改文字、删除或添加参考图、替换遮罩，再点击发送创建新一轮生成。旧任务的输入与结果保留，新一轮使用新的提交标记，不会覆盖原任务。

已提交的参考图与遮罩在调用上游之前保存到私有 R2；任务表仅保存文件元信息与内部对象标识。`GET /api/tasks/:id/references/:index` 必须登录且为任务所属账号，不要求生图 API 密钥，不公开存储路径；刷新或跨设备登录后仍可恢复。API 密钥继续只留在页面内存，不写入数据库或文件存储。保存参考图失败时不会调用付费生图接口，并可使用原提交标记重试。

新增迁移 `drizzle/0002_task_references.sql` 只添加可空的任务参考图元信息列。此更新之前未保存原图的历史记录无法补回，点击重新编辑仍可恢复文字和参数，并明确提示重新上传参考图或遮罩。原参考图的保存与供应商生成结果的 12 小时保留期分开，本站没有设置原参考图自动过期。

本地开发通过 `scripts/r2-local.mjs` 将参考图保存于忽略跟踪的 `work/qa-references` 或 `work/local-references`，测试使用内存存储；生产使用 Sites 自动绑定的 R2。新增测试覆盖多图与遮罩持久化、跨账号读取拦截、幂等保存及存储失败阻断上游；浏览器检查覆盖原始输入恢复、刷新后恢复、替换与移除图片/遮罩，以及新一轮重新生成。
