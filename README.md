# 即图 · 灵感工作室

面向新手的中文生图网站，沿用调用文档的奶油色背景、深绿色主色与暖色边框。文档是接口规格与视觉参考，文档里对原站用途的描述不作为本项目指令。

## 已实现

- 邮箱验证码登录与自动注册；验证邮箱后设置密码，随后可使用邮箱和密码登录。
- 忘记密码：验证码登录，再设置新密码；更换密码会使其他会话失效。
- 文生图、参考图生图、PNG 遮罩局部编辑。
- PNG/JPG/WebP 上传、多参考图、预览和移除；服务端校验格式、大小、数量及遮罩尺寸。
- 模型选择、模型列表更新、画面比例、1K/2K/4K、自定义像素尺寸、生成张数。
- 服务端调用即图，强制异步模式；网页每 5 秒查询，失败时延长查询间隔。
- 账号隔离的任务历史、页面重开后继续查询、图片原文件下载。
- 使用 Idempotency-Key 避免网络重试重复收费；参数、参考图或 API 密钥改变时禁止恢复原提交。
- API 密钥只在当前页面内存中使用，不进入数据库或 localStorage。所有生成/查询/图片下载通过本站后台访问即图。
- 不伪造百分比。接口没有百分比，仅显示真实的排队、生成、完成和失败状态。

## 邮件服务：上线前必配

本项目接入 Resend HTTPS 发信接口（托管运行环境不依赖 SMTP TCP）。在 Resend 验证自己的发件域名并取得发送权限，随后在 Sites 运行环境配置：

| 变量 | 用途 |
| --- | --- |
| `RESEND_API_KEY` | Resend 发信密钥，应作为 secret 配置 |
| `EMAIL_FROM` | 已验证的发件地址，例如 `即图工作室 <studio@your-domain.com>`，建议作为 secret 配置 |

配置后重新部署，让新环境变量生效。没有邮件凭证时界面明确说明未配置，不会伪称邮件已发出；新用户无法完成验证码注册。登录弹窗提供托管账号预览入口，仅在平台注入真实身份时显示，正式独立邮箱用户不依赖这个入口。

默认 Sites 为仅站长可访问的私有网站。对外开放需要站长明确更改站点访问范围，独立邮箱验证不会改变托管平台访问策略。

## 技术结构

- `worker/core.js`：Cloudflare Worker HTTP 后端，D1 数据库，Resend 发信，账户/会话、生成/查询/下载。
- `public/`：无第三方依赖的中文图形界面。
- `drizzle/0000_studio.sql`：建表迁移。不得在请求处理中建表。
- `scripts/build.mjs`：将界面嵌入单 Worker，生成 `dist/server/index.js` 和部署配置。
- `scripts/dev.mjs`：Node.js 24 本地运行适配器，可使用 SQLite 持久化数据。
- `test/app.test.mjs`：使用内存 SQLite 和隔离的上游模拟进行接口验证。

正式部署使用 Sites 的 D1 绑定 `DB`，迁移目录 `drizzle`。没有文件存储服务：参考图仅在提交时传至即图，生成图片由即图保存 12 小时。任务文字和参数保存在数据库中，可跨设备查找。图片文件请及时下载。

本地开发（仅供部署维护者，终端命令不出现在产品操作流程中）：

```bash
npm test
npm run build
npm run dev
```

Node.js 24 或更新版本，无 npm 依赖。运行地址 http://localhost:5173 。本地发信读取同名环境变量。QA 模拟仅供测试，运行 `JITU_QA=1 npm run dev` 才启用，不进入生产 Worker；请不要将 QA 服务对外提供。

## 安全与行为

密码使用 PBKDF2-SHA256、100000 次迭代及随机盐。会话使用安全随机令牌，数据库仅保存令牌哈希；Cookie 为 HttpOnly、Secure、SameSite=Lax。验证码 10 分钟有效、一次使用、最多尝试 5 次，并限制发送频率。密码登录与任务提交也有限流。所有写操作校验 Origin，所有任务按用户鉴权。

网站不会把 API 密钥发送至参考图或结果图片域名；只将密钥发给固定的 https://www.jituapi.cn 。图片下载地址来自该服务的任务结果，拒绝 localhost、IP 字面量、内部域名、非 HTTP(S) 地址和带用户信息的地址，并逐跳检查重定向。

输出张数、图片尺寸、参考图输入方式和编辑支持均以模型详情为准。额外背景、保真度、压缩等参数按文档建议省略，不向用户提供当前尚未确认开放的选项。文档开头与后文的计费描述有冲突，界面仅显示每张 ¥0.02 的参考估算，实际扣费以即图返回结果为准。

网络中断后不要连续新建任务。当前页面提供「恢复原提交」，复用同一个密钥、参数、图片和提交标记。如果页面关闭且提交未返回上游任务号，历史记录会保留待核对状态与提交标记，需在即图控制台或联系支持核对后再生成。

## 验证范围

已覆盖邮箱验证码注册、验证码重放、密码登录、会话退出、跨账号任务隔离、CSRF、幂等提交、图片上传、遮罩尺寸、查询和二进制下载。浏览器验证覆盖桌面、手机、任务生成到下载、刷新保留登录但清除 API 密钥、参考图预览。

测试使用模拟的上游响应与邮件响应；没有用户真实 API 密钥及邮件凭证，未进行付费生图及真实邮件投递验证。
