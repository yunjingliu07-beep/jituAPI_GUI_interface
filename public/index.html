A LITTLE GUIDE

新手使用指引

01

登录并连接密钥

使用邮箱和密码注册或登录，在 API 供应商官网创建普通渠道密钥，通过输入框下方的「切换API」添加并命名密钥；可保存多把密钥，按需要切换。

02

选择模式，描述画面

文生图只需文字；图生图需要参考图片；局部编辑还需 PNG 遮罩，透明区域代表修改范围。

03

安心等待，一键下载

每个会话独立记录创作；可同时打开多个会话，切换不会中断已受理的生成。结果保留 12 小时，请及时下载。

新任务会消耗 API 供应商账户余额；查询不额外扣费。实际价格、支持的尺寸和张数请以对应模型详情为准。
