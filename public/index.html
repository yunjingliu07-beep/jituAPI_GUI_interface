A LITTLE GUIDE

三步，把灵感变成图片

01

登录并连接密钥

使用邮箱和密码注册或登录，在 API 供应商官网创建普通渠道密钥，粘贴到「连接我的 API」。

02

选择模式，描述画面

文生图只需文字；图生图需要参考图片；局部编辑还需 PNG 遮罩，透明区域代表修改范围。

03

安心等待，一键下载

网页每 5 秒自动查询一次。任务开始后可在「我的作品」中找回；结果保留 12 小时。

新任务会消耗 API 供应商账户余额；查询不额外扣费。实际价格、支持的尺寸和张数请以对应模型详情为准。
